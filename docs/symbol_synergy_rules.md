# DiceGod — 심볼 조합 시너지 규칙

> 기준일: 2026-08-29

## 목표

심볼 조합은 단순히 같은 심볼을 많이 모으는 방식이 아니라, **주사위 결과 + 런 장비 선택**으로 빌드 방향을 만드는 것을 목표로 한다.

## 기본 규칙

1. 6개 주사위의 결과는 먼저 기본 심볼 효과를 적용한다.
2. 2개 조합 시너지는 요구 심볼 수량을 만족하면 1회 발동한다.
3. 3개 조합 시너지는 요구 심볼 수량을 만족하면 발동하지만, 한 번의 굴림에서 최대 2개까지만 발동한다.
4. 같은 시너지는 심볼이 4개, 5개, 6개로 늘어나도 반복 발동하지 않는다.
5. 단일 심볼 시너지는 해당 심볼 장비 태그가 필요하다.
6. 혼합 시너지는 구성 심볼 중 하나에 대응하는 장비 태그가 있으면 활성화된다.
7. 장비 태그가 없으면 기본 심볼 효과만 적용되며 시너지는 발동하지 않는다.
8. 시너지 효과는 해당 턴의 결과에만 적용되고, 다음 턴에 누적되지 않는다.

## 의도된 빌드 방향

| 방향 | 핵심 심볼 | 특징 |
| --- | --- | --- |
| 공격 | 검 | 안정적인 추가 피해 |
| 관통 | 활 | 방어를 무시하는 피해 |
| 마법 | 지팡이 | 상태 효과 중심 |
| 연타 | 표창 | 추가 타격 중심 |
| 방어 | 방패 | 보호막 + 반격 |
| 회복 | 힐 | 회복 + 보호 |
| 하이브리드 | 검+방패 / 활+표창 / 지팡이+힐 | 두 역할을 동시에 강화 |

## 밸런스 안전장치

- 3단계 시너지 최대 2개 제한으로 한 번의 굴림에 모든 고급 시너지가 폭발하는 상황을 방지한다.
- 시너지 자체는 런 장비 선택과 연결되므로 모든 플레이어가 모든 시너지를 동시에 사용할 수 없다.
- 기본 심볼 효과는 항상 남아 있어 시너지가 없는 초반 런도 정상적으로 플레이할 수 있다.
- 밸런스 검증은 실제 전투에서 사용하는 `SymbolSkillSystem.evaluate_counts()`와 동일한 계산 규칙을 사용한다.

## 검증 기준

- 기본 심볼만 있을 때 공격/방어/회복 값이 유지되어야 한다.
- 단일 심볼 2개 + 대응 장비에서 해당 2단계 시너지가 정확히 1회 발동해야 한다.
- 3개 + 대응 장비에서 2단계와 3단계 시너지가 각각 1회씩 발동해야 한다.
- 서로 다른 3단계 시너지가 동시에 조건을 만족해도 최대 2개까지만 발동해야 한다.
- 대표 공격/방어/회복/연타/마법 프로필의 결과가 음수가 아니어야 한다.
