## 현재 실제 런 구조

일반 전투 → 골드 보상 → 랜덤 이벤트(선택/스킵) → 엘리트 → 골드 보상 → 랜덤 이벤트(선택/스킵) → 보스 → 신성 심볼 각인 + 보스 전용 장비/특수 주사위 → 런 클리어

사망 시: 보유 주사위 6개 중 정확히 1개 선택 → 6면/대장간 변경/강화/신성 심볼 정보를 보존 → 다음 런에서 계승 주사위 1개 + 기본 주사위 5개.

## 검증 상태

코드와 씬 연결은 `main`에 반영했다. 현재 실행 환경에는 Godot 바이너리가 설치되어 있지 않아 이 대화 환경에서 실제 Web 브라우저 실행/1280×720 픽셀 회귀 테스트까지 직접 수행할 수는 없다. GitHub Actions의 기존 Web Export workflow가 실제 Godot 4.7.2 환경에서 최종 import/export 검증을 담당한다.

따라서 기능 구현과 연결은 완료 상태이며, 최종 남은 검증은 Web Export/브라우저에서의 실제 픽셀·입력 회귀 확인이다.
