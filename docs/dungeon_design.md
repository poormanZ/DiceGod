# DiceGod — 던전 설계

## 1. 전체 구조

DiceGod은 로그라이크 방식으로 던전을 탐험합니다.

전투
→ 보상
→ 선택
→ 전투
→ 이벤트 / 상점 / 주사위 강화
→ 엘리트
→ 보스

## 2. 던전 노드

- 일반 전투
- 엘리트 전투
- 보스
- 상점
- 이벤트
- 휴식
- 심볼 주사위 강화
- 보물

## 3. 보상

가능한 보상:

- 새로운 심볼 주사위
- 기존 주사위 심볼 분포 변경
- 주사위 추가
- 스킬
- 장비
- 골드
- 회복

## 4. 심볼 중심 선택

보상 선택에서 단순히 더 강한 수치를 주는 대신 플레이어가 원하는 심볼 전략을 선택하게 합니다.

예:

- 공격 심볼 확률 증가
- 방패 확률 증가
- 힐 확률 증가
- 특정 심볼 특화 주사위

## 5. 상점

향후 상점에서는 다음 상품을 제공합니다.

- 공격형 주사위
- 방어형 주사위
- 회복형 주사위
- 특정 심볼 특화 장비
- 리롤/잠금 강화

## 6. 이벤트

이벤트도 심볼을 기준으로 선택지를 만듭니다.

예:

> 검의 힘을 강화할 것인가, 힐 심볼을 강화할 것인가?

## 7. 프로토타입

현재 던전 구조는 유지하되, 보상과 상점의 콘텐츠를 심볼 시스템에 맞춰 단계적으로 교체합니다.
