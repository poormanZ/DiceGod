# DiceGod — 던전 설계

## 현재 진행 구조

현재 런은 일반 전투를 중심으로 이벤트, 엘리트, 보스가 연결되는 구조입니다.

- 일반 전투
- 골드/보상
- 이벤트
- 엘리트 전투
- 이벤트
- 보스 전투
- 런 종료 또는 후속 성장/환생 흐름

이벤트 종류에는 캠프, 상점, 대장간, 도박장이 있습니다.

## 심볼 중심 보상

향후 보상은 단순 수치 상승보다 다음을 우선합니다.

- 특정 심볼 확률 조정
- 특정 면 변경
- 심볼 강화
- 스킬/장비와의 시너지

## 현재 구현과 미래 설계 구분

던전 노드와 이벤트 씬은 이미 존재하지만 모든 기획된 보상/상점/대장간 기능이 최종 형태로 완성된 것은 아닙니다. 로드맵의 완료 여부는 실제 코드와 CI 검증을 기준으로 판단합니다.
