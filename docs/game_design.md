# DiceGod — 전체 게임 기획

## 1. 게임 개요
DiceGod은 **행동 심볼 주사위**를 이용해 운과 전략을 결합하는 2D 턴제 로그라이크 던전 RPG입니다.

플레이어는 던전을 탐험하며 주사위, 스킬, 장비를 획득하고 심볼 조합을 중심으로 빌드를 만듭니다.

## 2. 핵심 컨셉

> 주사위가 이렇게 나왔을 때, 나는 이번 턴에 필요한 행동을 어떻게 만들 것인가?

주사위는 높은 숫자를 뽑는 장치가 아니라 **공격·방어·치료 행동을 만드는 자원**입니다.

## 3. 핵심 심볼

- ⚔️ 검 — 공격
- 🏹 활 — 공격
- 🪄 지팡이 — 공격
- ✦ 표창 — 공격
- 🛡️ 방패 — 방어
- ✚ 힐 — 치료

초기에는 공격 심볼 4종이 모두 1 공격입니다. 심볼별 개성은 스킬·장비·특수 주사위로 확장합니다.

## 4. 핵심 게임 루프

### 던전
전투 → 보상 → 선택 → 전투 → 이벤트/상점 → 엘리트 → 보스

### 전투
주사위 굴림 → 잠금 → 1회 리롤 → 심볼 확정 → 공격/방어/치료 집계 → 스킬 → 행동 → 적 행동

## 5. 핵심 설계 원칙

### 주사위가 게임의 중심
심볼 주사위가 빌드와 전투를 동시에 결정합니다.

### 운에는 개입할 수 있어야 함
잠금과 리롤로 원하는 심볼을 확보할 수 있어야 합니다.

### 빌드를 만드는 재미
주사위 + 스킬 + 장비가 특정 심볼을 강화하고 서로 시너지를 만들어야 합니다.

### 매 턴 선택이 중요해야 함
공격을 더 할지, 방패를 확보할지, 힐을 노릴지 판단하게 합니다.

### 런마다 다른 경험
매 런 다른 심볼 분포와 시너지로 플레이하게 합니다.

## 6. 빌드 예시

### 검 빌드
검 심볼을 강화하고 직접 공격/강타를 강화합니다.

### 활 빌드
활 심볼을 이용해 관통과 약점 공격을 강화합니다.

### 마법 빌드
지팡이 심볼로 상태 이상과 원소 효과를 강화합니다.

### 암살 빌드
표창 심볼을 이용해 연타와 치명타를 강화합니다.

### 수호 빌드
방패를 많이 확보하고 방어를 반격/보호막으로 전환합니다.

### 성직자 빌드
힐 심볼을 강화하고 회복을 보호막/지원 효과로 연결합니다.

## 7. 로그라이크 구조

런 중 획득한 주사위·스킬·장비로 심볼 빌드를 구성합니다.
런이 종료되면 런 빌드는 초기화되며 영구 해금은 유지됩니다.

## 8. 프로토타입 목표

현재 전환 단계의 목표는 다음입니다.

- 플레이어 1명
- 적 1마리
- 심볼 주사위 3개
- 잠금
- 1회 리롤
- 심볼 확정
- 공격/방어/치료 처리
- 승리/패배

이 핵심 루프가 재미있는지 검증한 뒤 6개 주사위와 콘텐츠를 확장합니다.
