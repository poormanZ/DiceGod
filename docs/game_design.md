# DiceGod — 전체 게임 기획

## 1. 게임 개요

DiceGod은 **행동 심볼 주사위**를 이용해 운과 전략을 결합하는 2D 턴제 로그라이크 던전 RPG입니다.

주사위는 높은 숫자를 뽑는 장치가 아니라 **이번 턴에 필요한 행동을 만드는 자원**입니다.

## 2. 기본 심볼

- ⚔️ 검 — 공격
- 🏹 활 — 공격
- 🔮 지팡이 — 공격 / 마법
- 🗡️ 표창 — 공격 / 연타
- 🛡️ 방패 — 방어
- ❤️ 힐 — 치료

기본 주사위 1개에는 6개 심볼이 하나씩 들어갑니다.

## 3. 핵심 전투 루프

전투 시작 → 6개 주사위 굴림 → 원하는 주사위 잠금 → 1회 리롤 → 결과 확정 → 심볼 집계 → 공격/방어/치료 → 적 행동

## 4. 게임 루프

일반 전투 → 보상 → 이벤트/상점 → 엘리트 → 이벤트 → 보스 → 보상 → 런 종료

## 5. 빌드 방향

기존 숫자 기반 빌드와 전투 전 빌드 선택 화면은 폐기합니다.

새 빌드 시스템은 심볼 주사위가 확정된 이후의 플레이 경험을 기준으로 추후 설계합니다.

예정 방향:

- 특정 심볼 확률 강화
- 특정 심볼 조합 강화
- 주사위 면 교체/강화
- 스킬과 장비의 심볼 시너지
- 심볼 조합에 따른 전투 스타일 변화

## 6. 설계 원칙

### 주사위가 게임의 중심
심볼 주사위가 매 턴의 행동을 결정합니다.

### 운에 개입할 수 있어야 함
잠금과 리롤을 통해 결과를 조정합니다.

### 매 턴 선택이 중요해야 함
공격, 방어, 치료 중 무엇을 우선할지 판단합니다.

### 숫자보다 행동
게임의 핵심 질문은 '높은 숫자가 나왔는가?'가 아니라 **'이번 턴에 필요한 심볼을 만들었는가?'**입니다.
