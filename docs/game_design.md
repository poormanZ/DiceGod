# DiceGod — 전체 게임 기획

## 현재 구현 목표

DiceGod은 높은 숫자를 만드는 게임이 아니라 **이번 턴에 필요한 행동 심볼을 만드는 게임**입니다.

### 기본 심볼

| 심볼 | 역할 |
|---|---|
| ⚔️ 검 | 공격 |
| 🏹 활 | 공격 |
| 🔮 지팡이 | 공격/마법 계열 |
| 🗡️ 표창 | 공격/연타 계열 |
| 🛡️ 방패 | 보호막 |
| ❤️ 힐 | 치료 |

기본 주사위 하나에는 위 6면이 하나씩 들어가며 현재 런은 기본적으로 6개 주사위로 시작합니다.

## 현재 전투 루프

6개 굴림 → 주사위 잠금 → 턴당 1회 리롤 → 결과 확정 → 심볼 집계 → 치료/보호막 적용 → 공격/행동 → 적 행동

전투 전 빌드 선택은 사용하지 않습니다.

## 현재 로그라이크 루프

일반 전투 → 보상/골드 → 확정된 이벤트 → 엘리트 → 확정된 이벤트 → 보스 → 런 종료/환생 계열 시스템

던전/상점/대장간/도박장/환생 관련 코드는 존재하지만 세부 콘텐츠는 계속 정리 중입니다. 따라서 구현된 UI와 미래 기획을 동일하게 취급하지 않습니다.

## 설계 원칙

- 숫자 합산을 전투의 기본 의미로 사용하지 않습니다.
- 심볼을 잠그고 리롤하는 선택을 핵심 재미로 둡니다.
- 데이터와 런타임 계산을 분리합니다.
- 심볼 고유 효과와 빌드 시스템은 현재 기본 전투를 안정화한 뒤 확장합니다.
