# DiceGod — 로그라이크 확장 설계

> 상태: 미래 확장안. 아래 내용은 현재 구현 완료 목록이 아닙니다.

## 목표

`주사위를 모으는 것`보다 `주사위의 6면을 직접 조정하고 다음 런에 의미 있는 선택을 남기는 것`을 장기 목표로 합니다.

## 확장 후보

- 대장간에서 특정 면의 심볼 변경
- 면 강화/태그
- 도박장 미니게임
- 엘리트별 심볼 카운터 패턴
- 보스별 심볼 콘셉트
- 보스 전용 주사위/장비
- 환생 시 주사위 1개 계승
- 신성 심볼

## 현재 우선순위

위 시스템보다 먼저 6개 기본 심볼 주사위의 굴림/잠금/리롤/확정과 전투 피드백을 안정화합니다.

## 밸런스 원칙

강한 주사위 하나만 만드는 것보다 어떤 심볼을 모으고 어떤 면을 포기할지 선택하게 하는 것이 중요합니다.
