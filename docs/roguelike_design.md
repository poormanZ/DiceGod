# DiceGod — 로그라이크 시스템 상세 기획

## 핵심 방향

DiceGod는 `주사위를 모으는 게임`이 아니라 `주사위를 직접 만들어 다음 생에 남기는 게임`으로 설계한다.

## 런 구조

일반 전투 → 골드 보상 → 랜덤 이벤트 선택/스킵 → 엘리트 → 랜덤 이벤트 선택/스킵 → 보스 → 보스 전용 장비/주사위 보상 → 런 종료/환생

## 랜덤 이벤트

### 캠프
- HP 회복
- 선택형으로 회복 또는 다음 전투 보너스
- 안전하지만 직접적인 빌드 성장은 적음

### 상점
- 장비와 주사위 판매
- 3~5개의 랜덤 상품
- 새로고침 비용 증가
- 희귀 상품 슬롯 운영

### 대장간

DiceGod의 핵심 빌드 제작 시설.

**주사위 선택 → 6개 면 중 정확히 1개 선택 → 원하는 심볼 선택 → 골드 지불 → 해당 면을 선택한 심볼로 변경**

예:

`⚔️ ⚔️ 🏹 🛡️ ✚ 杖`

에서 🛡️ 면을 ⚔️로 변경하면:

`⚔️ ⚔️ 🏹 ⚔️ ✚ 杖`

가 된다.

대장간 개조 비용은 기본 비용이 있으며 같은 주사위를 반복 개조할수록 증가한다. 보스 전용 주사위는 일부 개조 제한을 둘 수 있다.

면 변경과 별개로 면 강화 태그를 제공한다. 강화는 숫자 폭증보다 해당 심볼의 조합/특수 효과를 강화하는 방향으로 설계한다.

### 도박장

보유 주사위를 활용하는 미니게임.

- 심볼 계열 맞히기
- 주사위 3회 굴림
- 2~3개 주사위 조합 도박
- 특정 심볼 연속 등장 도전

보상은 골드, 상점 할인, 대장간 무료 개조권, 일시 버프, 희귀 주사위 등으로 구성한다. 기본적으로 실패해도 주사위 자체를 잃지 않으며 골드와 기회비용으로 위험을 만든다.

## 엘리트

엘리트는 단순히 HP만 높은 적이 아니라 현재 빌드의 약점을 시험한다.

예:
- 철갑 기사: 높은 방어, 관통 유리
- 흡혈 마도사: 장기전에서 회복
- 광전사: 턴이 길수록 강해짐
- 주사위 도둑: 특정 심볼 봉인

## 보스

각 보스는 하나의 빌드 콘셉트를 가진다.

- 화염 군주: 지팡이/화상
- 검의 군주: 강타/방패
- 사냥꾼 왕: 관통/연타

보스 처치 후 `특수 장비 2개 중 1개 + 특수 주사위 2개 중 1개`를 선택하는 구조를 기본안으로 한다.

## 죽음과 환생

사망 시 다음을 잃는다.

- 골드
- 일반 장비
- 런 진행도
- 일반 주사위 5개
- 런 중 임시 강화

대신 **마지막 보유 주사위 중 정확히 1개를 선택해 다음 환생으로 계승한다.**

다음 런은:

**계승 주사위 1개 + 기본 주사위 5개**

로 시작한다.

계승 주사위는 다음을 유지한다.

- 6개 면 구성
- 대장간으로 변경한 심볼
- 면 강화
- 특수 태그
- 보스 전용 주사위의 고유 효과

따라서 죽음 직전의 마지막 선택 자체가 중요한 게임 플레이가 된다.

### 계승의 밸런스

계승 주사위 하나만 강력하고 나머지 5개는 기본 주사위이므로 새로운 런에서는 다시 빌드를 만들어야 한다. 영구 스탯을 크게 올리기보다는 새로운 주사위/장비/보스/이벤트를 해금해 선택지를 넓힌다.

## 장기 성장

### 운명 주사위

대장간 개조 누적, 엘리트 처치, 보스 처치, 특정 심볼 조합 승리 등의 조건으로 `운명` 태그를 얻는다. 환생 시 계승 가치가 높은 주사위가 된다.

### 저주 주사위

강력하지만 페널티를 가진 희귀 주사위.

예:
- 공격 심볼이 많지만 치료 심볼 사용 불가
- 공격은 강하지만 전투 종료 후 HP 감소
- 특정 조합은 매우 강하지만 리롤 효율 감소

### 주사위 완성도

한 주사위의 6면 구성 자체를 목표로 만든다.

- ⚔️ 6면: 광전사
- 🏹 6면: 저격수
- 杖 6면: 대마법사
- 🛡️ 6면: 성벽
- ✚ 6면: 성녀

혼합 완성도도 제공한다.

- ⚔️ + 🛡️: 반격 기사
- 🏹 + ✦: 연사 사냥꾼
- 杖 + ✚: 성화술사
- 🛡️ + ✚: 성기사

## 추가 재미 요소

### 위기 보너스
HP가 낮을 때 특정 조합이 역전 효과를 얻는다. 예: HP 30% 이하에서 ⚔️ 3개 → 광전사의 일격.

### 엘리트 위험 계약
엘리트 진입 전에 `치료 심볼 사용 불가 대신 골드 +50%`처럼 불리한 조건을 선택하면 보상을 높인다.

### 보스 전조
보스 직전 보스의 핵심 패턴 일부를 공개해 마지막 상점/대장간 선택에 의미를 준다.

### 빌드 발견 도감
처음 완성한 조합을 도감에 기록하고 새로운 선택지를 해금한다.

## 핵심 전략 축

1. 전투 — 이번 턴에 어떤 심볼을 만들 것인가?
2. 골드 — 어디에 투자할 것인가?
3. 대장간 — 어느 면을 원하는 심볼로 바꿀 것인가?
4. 위험 — 엘리트/도박/저주를 감수할 것인가?
5. 환생 — 죽을 때 어떤 주사위를 남길 것인가?

## 감정 곡선

초반: 약함 → 특화 방향 발견

중반: 주사위 획득 → 대장간 개조 → 장비 확보 → 빌드 완성

후반: 엘리트 시험 → 위험 이벤트 → 보스 준비

최종: 보스 처치 → 고유 보상 → 최고의 주사위 제작

사망: 모든 것을 잃음 → 단 하나의 주사위 선택 → 다음 환생의 유산 확보

## 개발 우선순위

1. 전투 종료 골드
2. 런 골드 저장
3. 전투 → 이벤트 → 엘리트 → 이벤트 → 보스 상태 머신
4. 이벤트 선택/스킵
5. 캠프
6. 상점
7. **대장간에서 주사위 6면 중 하나를 원하는 심볼로 변경**
8. 대장간 면 강화
9. 주사위 획득/교체
10. 도박장
11. 엘리트 패턴
12. 보스 패턴
13. 보스 전용 장비/주사위
14. 사망 화면
15. **환생 시 주사위 1개 계승**
16. 계승 주사위 저장/복원
17. 메타 해금
18. 완성도/혼합 조합 보너스
19. 전체 런 회귀 테스트
