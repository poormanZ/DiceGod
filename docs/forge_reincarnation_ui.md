# DiceGod — 대장간 / 유산 UI 설계

> 기준일: 2026-08-28

## 1. 대장간 목표

대장간은 **현재 런의 주사위를 직접 개조하는 장소**입니다.

1. 현재 골드/비용 표시
2. 6개 주사위 선택
3. 선택 주사위의 6면 표시
4. 변경할 면 선택
5. 변경 가능한 심볼 표시
6. 변경 전/후 미리보기
7. 강화/태그 효과 미리보기
8. 최종 확인

대장간에서 발생한 면 변경/강화는 현재 런에만 적용됩니다.

## 2. 대장간의 선택 구조

면을 바꾸는 것은 단순한 상향이 아닙니다.

예:

`❤️ → ⚔️`

공격 기회는 늘어나지만 회복 기회는 줄어듭니다.

따라서 모든 변경은 기회비용을 갖도록 설계합니다.

## 3. 기존 환생 주사위 폐기

기존의 **강화된 주사위 1개를 그대로 다음 런으로 가져가는 환생 방식은 폐기**합니다.

현재 런의 완성된 주사위 면/강화 상태를 영구 전투력으로 저장하지 않습니다.

## 4. 유산 UI

환생 화면은 '주사위 계승'이 아니라 **유산 선택 화면**으로 재정의합니다.

표시 정보:

- 이번 런의 주요 성과
- 해금된 콘텐츠
- 획득한 메타 재화
- 사용 가능한 유산
- 유산의 다음 런 영향
- 현재 장착 슬롯

### 유산 예시

- 전사의 유산 — 공격 심볼 관련 선택지 확대
- 수호자의 유산 — 방패/힐 선택지 확대
- 마법사의 유산 — 지팡이 관련 선택지 확대
- 도박사의 유산 — 고위험 이벤트 해금
- 신성의 유산 — 신성 심볼 콘텐츠 해금

유산은 완성형 주사위를 지급하지 않습니다.

## 5. UI 기준

- 1280×720
- 6개 주사위 3×2
- 선택 상태 명확화
- 변경 전/후 차이 명확화
- 유산의 영구 효과와 런 효과를 구분 표시
- 잘못된 선택을 방지하는 최종 확인
