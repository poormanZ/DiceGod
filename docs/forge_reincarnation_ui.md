# DiceGod — 대장간 / 환생 UI 설계

> 상태: 확장 UI 설계. 현재 화면 구현과 최종 기획을 구분합니다.

## 대장간 목표

1. 현재 골드와 비용 표시
2. 6개 주사위 선택
3. 선택 주사위의 6면 표시
4. 변경할 면 1개 선택
5. 기본 심볼 선택
6. 변경 전/후 미리보기
7. 최종 확인

현재 대장간 상태에는 런당 사용 여부와 면 변경/강화 기록을 저장하는 구조가 있습니다.

## 환생 목표

사망 시 보유 주사위 중 정확히 1개를 선택하고 다음 런의 유산으로 저장합니다.

계승 데이터 후보:

- 6면 구성
- 대장간 변경 기록
- 면 강화
- 신성 심볼 기록
- 특수 태그

## UI 기준

- 1280×720
- 6개 주사위는 3×2
- 선택 상태 명확화
- 잘못된 계승 선택 방지를 위한 최종 확인
