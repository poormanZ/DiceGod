# DiceGod — 대장간 / 환생 UI 설계

## 대장간

화면 구성:

1. 상단: 현재 골드 / 대장간 비용
2. 중앙: 주사위 6개를 3×2로 표시
3. 주사위 선택 시 하단에 6개 면 표시
4. 수정할 면 1개 선택
5. 심볼 선택 패널 표시
   - ⚔️ 검
   - 🏹 활
   - 杖 지팡이
   - ✦ 표창
   - 🛡️ 방패
   - ✚ 힐
6. 변경 전/후 미리보기
7. `35G로 각인` 버튼
8. 한 런에서 기본 대장간 변경은 1회로 제한

## 대장간의 재미 요소

- 단순 강화가 아니라 원하는 면을 원하는 심볼로 바꾼다.
- 같은 심볼을 모아 특화 주사위를 만들 수 있다.
- 보스 신성 심볼은 일반 심볼과 별도의 각인 단계로 제공한다.
- 향후 대장간 업그레이드로 1회 추가 개조, 심볼 잠금, 비용 할인 등을 해금할 수 있다.

## 환생

사망 시:

1. `이번 생은 끝났다` 화면
2. 현재 보유한 6개 주사위 전체 표시
3. 각 주사위의 6개 면을 크게 표시
4. 신성 심볼이 각인된 면은 별도 강조
5. **딱 1개의 주사위만 선택 가능**
6. 선택한 주사위를 다음 생의 첫 번째 주사위로 계승
7. 나머지 주사위/현재 골드/일회성 이벤트 상태는 소멸
8. 환생 시작

## 환생의 핵심 재미

죽을수록 모든 것을 잃지만, 가장 가치 있는 주사위 하나는 남길 수 있다.

따라서 플레이어는 런 중간부터:

- `이번 런을 끝까지 밀어볼 것인가?`
- `좋은 주사위를 확보했으니 안전하게 계승할 것인가?`
- `보스까지 도전해 신성 심볼을 붙인 뒤 계승할 것인가?`

를 판단한다.

## UI 원칙

- 1280×720 기준
- 주사위는 항상 3×2
- 선택 상태는 명확하게 강조
- 버튼에는 현재 골드와 비용을 함께 표시
- 환생 화면에서는 `계승 1/1`을 항상 표시
- 잘못된 선택을 방지하기 위해 최종 확인 팝업 제공
