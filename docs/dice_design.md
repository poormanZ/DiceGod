# DiceGod — 심볼 주사위 설계

## 1. 주사위의 역할

주사위는 DiceGod의 가장 중요한 전투 자원입니다.

기존의 `1~6 숫자 → 공격력 합산` 방식은 폐기합니다.
각 면에는 숫자 대신 행동 심볼이 존재하며, 플레이어는 필요한 행동 심볼을 만들고 잠그고 리롤하는 방식으로 매 턴의 행동을 설계합니다.

핵심 심볼:

| 심볼 | 의미 | 기본 효과 |
|---|---|---|
| ⚔️ 검 | 공격 | 공격 자원 +1 |
| 🏹 활 | 공격 | 공격 자원 +1 |
| 🪄 지팡이 | 공격 | 공격 자원 +1 |
| ✦ 표창 | 공격 | 공격 자원 +1 |
| 🛡️ 방패 | 방어 | 방어 자원 +1 |
| ✚ 힐 | 치료 | HP 회복 +1 |

초기에는 네 공격 심볼의 기본 가치가 동일합니다. 이후 스킬·장비·특수 주사위가 심볼별 차이를 만듭니다.

## 2. 기본 심볼 주사위

기본 6면:

`⚔️ / 🏹 / 🪄 / ✦ / 🛡️ / ✚`

주사위의 내부 값은 심볼을 식별하기 위한 ID일 뿐, 공격력이나 회복량을 의미하지 않습니다.

## 3. 주사위 개수

- 기본: 3개
- 목표 최대: 6개
- 현재 전환 단계 UI: 3개

6개 확장은 주사위 슬롯 UI를 먼저 확장한 뒤 적용합니다.

## 4. 잠금

굴린 뒤 원하는 심볼을 잠글 수 있습니다.

예:

`⚔️ / 🛡️ / ✚`

→ 방패가 필요하면 `🛡️`를 잠금
→ 공격이 더 필요하면 `⚔️`를 잠금
→ 힐이 필요 없으면 `✚`를 리롤 대상으로 유지

잠긴 주사위는 리롤되지 않습니다.

## 5. 리롤

기본 규칙은 턴당 1회입니다.

잠기지 않은 주사위만 리롤합니다.

리롤의 목적은 높은 숫자를 찾는 것이 아니라 **필요한 행동 심볼 조합을 완성하는 것**입니다.

## 6. 결과 확정

최종 결과를 확정하면 심볼을 집계합니다.

예:

`⚔️ / 🪄 / 🛡️`

→ 공격 2
→ 방어 1
→ 치료 0

`🛡️ / ✚ / ✚`

→ 공격 0
→ 방어 1
→ 치료 2

## 7. 행동 처리

### 공격

검/활/지팡이/표창 1개당 기본 공격 자원 1을 제공합니다.

초기 공식:

`공격력 = 공격 심볼 개수 + 런/스킬 보너스`

### 방어

방패 1개당 기본 방어 자원 1을 제공합니다.

적의 공격 전에 방어 자원만큼 피해를 차감합니다.

### 치료

힐 1개당 HP 1을 회복합니다.

회복은 결과 확정 시 적용하며 최대 HP를 초과하지 않습니다.

## 8. 심볼별 장기 정체성

### 검
직접 공격, 강타, 근접 피해 강화.

### 활
관통, 약점 공격, 후열 공격.

### 지팡이
마법, 원소, 상태 이상.

### 표창
연타, 치명타, 추가 공격.

### 방패
방어, 반격, 보호막, 피해 전환.

### 힐
회복, 과회복, 지원, 회복을 보호막으로 전환.

초기에는 이 차이를 기본 수치로 만들지 않고 콘텐츠에서 점진적으로 도입합니다.

## 9. 특수 주사위

특수 주사위도 숫자 조작이 아니라 심볼 분포 조작으로 설계합니다.

예:

### 공격 주사위
`⚔️ / ⚔️ / 🏹 / 🪄 / ✦ / 🛡️`

### 수호 주사위
`🛡️ / 🛡️ / 🛡️ / ⚔️ / 🏹 / ✚`

### 회복 주사위
`✚ / ✚ / ✚ / 🛡️ / ⚔️ / 🏹`

### 표창 주사위
`✦ / ✦ / ✦ / ✦ / 🏹 / ⚔️`

## 10. 빌드 철학

좋은 주사위가 단순히 더 높은 숫자를 제공해서는 안 됩니다.

핵심은 현재 빌드가 원하는 심볼을 얼마나 안정적으로 제공하느냐입니다.

목표:

- 심볼 시너지
- 확률 조작
- 잠금/리롤 선택
- 공격과 생존의 균형
- 특정 심볼 몰빵의 위험과 보상

## 11. 폐기되는 숫자 기반 규칙

- 숫자 총합 공격력
- 홀수/짝수 조건
- 특정 숫자 6 강화
- 높은 숫자/낮은 숫자 도박
- 숫자 스트레이트 자체의 전투 가치

이러한 조건은 향후 심볼 조건으로 재설계합니다.
