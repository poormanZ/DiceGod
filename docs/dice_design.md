# DiceGod — 심볼 주사위 설계

## 1. 핵심 원칙

DiceGod의 주사위는 숫자를 굴려 합산하는 장치가 아니라 **행동 심볼을 생성하는 전투 자원**입니다.

기본 6면은 다음으로 고정합니다.

| 면 | 심볼 | 역할 |
|---|---|---|
| 1 | ⚔️ | 검 / 공격 |
| 2 | 🏹 | 활 / 공격 |
| 3 | 🔮 | 지팡이 / 공격·마법 |
| 4 | 🗡️ | 표창 / 공격·연타 |
| 5 | 🛡️ | 방패 / 방어 |
| 6 | ❤️ | 힐 / 치료 |

내부 값은 심볼 식별용 ID일 뿐 공격력이나 회복량을 의미하지 않습니다.

## 2. 현재 전투 주사위

- 기본 주사위: 6개
- 각 주사위: 위 6면 심볼 구성
- 잠금: 개별 지원
- 리롤: 턴당 1회
- 확정 후 심볼을 집계해 행동을 결정

## 3. 심볼 기본 효과

- ⚔️ 검 1개 → 공격 자원 +1
- 🏹 활 1개 → 공격 자원 +1
- 🔮 지팡이 1개 → 공격 자원 +1
- 🗡️ 표창 1개 → 공격 자원 +1
- 🛡️ 방패 1개 → 방어 자원 +1
- ❤️ 힐 1개 → HP +1

심볼별 고유 효과는 향후 스킬/장비 시스템과 함께 확장합니다.

## 4. 잠금과 리롤

플레이어는 원하는 심볼을 잠그고 나머지만 리롤합니다. 핵심 선택은 높은 숫자를 찾는 것이 아니라 **이번 턴에 필요한 행동 조합을 확보하는 것**입니다.

## 5. 빌드 시스템

기존 숫자 기반 빌드 트리는 폐기했습니다.

향후 빌드는 다음을 기준으로 새로 설계합니다.

- 심볼 등장 확률
- 특정 심볼 강화
- 동일 심볼 조합
- 서로 다른 공격 심볼 조합
- 주사위 면 교체/강화
- 스킬/장비와의 심볼 시너지

현재는 기존 특화 주사위 리소스를 유지하지 않으며, 새 빌드 설계가 완료된 뒤 필요한 주사위 리소스를 다시 추가합니다.

## 6. 폐기 규칙

다음 숫자 중심 규칙은 사용하지 않습니다.

- 숫자 합산 공격력
- 홀수/짝수 조건
- 높은 숫자/낮은 숫자 조건
- 숫자 스트레이트
- 숫자 동일값 기반 기존 빌드 조건
