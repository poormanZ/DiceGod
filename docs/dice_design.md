# DiceGod — 심볼 주사위 설계

## 현재 규칙

기본 주사위는 6면이며 각 면은 하나의 행동 심볼입니다.

| ID | 심볼 | 이름 | 기본 자원 |
|---:|---|---|---:|
| 1 | ⚔️ | 검 | 공격 +1 |
| 2 | 🏹 | 활 | 공격 +1 |
| 3 | 🔮 | 지팡이 | 공격 +1 |
| 4 | 🗡️ | 표창 | 공격 +1 |
| 5 | 🛡️ | 방패 | 보호막 +1 |
| 6 | ❤️ | 힐 | HP +1 |

내부 ID는 식별용이며 수치 크기를 의미하지 않습니다.

## 굴림

- 전투당 기본 주사위 6개
- 개별 잠금
- 턴당 리롤 1회
- 확정 전에는 잠금 변경 가능
- 모든 주사위에 결과가 있어야 확정 가능

`DiceData`는 정적 면 구성, `DiceRuntimeState`는 결과/잠금 상태, `DiceRoller`는 굴림 상태를 담당합니다.

## 향후 확장

주사위 면 교체/강화, 심볼 확률 조작, 조합 시너지, 신성 심볼 등은 현재 기본 규칙을 깨지 않는 별도 확장 계층으로 추가합니다.

## 폐기된 규칙

숫자 합산 공격력, 홀짝 조건, 스트레이트, 높은 숫자 보너스, 기존 숫자 빌드 선택은 현재 사양에서 사용하지 않습니다.
