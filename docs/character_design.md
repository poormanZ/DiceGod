# DiceGod — 캐릭터 / 스킬 / 장비 설계

## 캐릭터

현재 프로토타입은 단일 플레이어 캐릭터와 단순 HP/기본 공격 보너스/보호막 구조를 사용합니다.

## 스킬

스킬 조건은 숫자가 아니라 심볼 결과를 사용합니다. 현재 구현된 기본 스킬 계산은 공격 심볼의 동일 결과 2개 또는 3개입니다.

향후에는 다음처럼 심볼별 정체성을 분리합니다.

- ⚔️ 검: 강타
- 🏹 활: 관통
- 🔮 지팡이: 마법/상태이상
- 🗡️ 표창: 연타
- 🛡️ 방패: 반격/보호
- ❤️ 힐: 회복/보호막

## 장비

장비 시스템은 심볼 효과를 강화하는 방향을 유지합니다. 다만 현재 구현과 최종 기획을 혼동하지 않도록, 실제 적용 가능한 장비만 현재 로드맵의 완료 항목으로 취급합니다.

## 폐기된 조건

숫자 합계, 홀짝, 스트레이트, 높은 숫자일수록 강해지는 조건은 사용하지 않습니다.
