# DiceGod — 캐릭터 / 스킬 / 장비 설계

## 1. 캐릭터

첫 번째 프로토타입에서는 플레이어 캐릭터 1명만 사용합니다.

기본 능력치는 단순하게 유지합니다.

- HP
- 기본 공격 보너스
- 기본 생존 능력

## 2. 스킬

스킬은 숫자가 아니라 심볼을 조건으로 사용합니다.

예:

### 검의 강타
검 심볼 2개 이상이면 추가 공격.

### 활의 관통
활 심볼이 포함된 공격은 방어를 일부 관통.

### 마법 폭발
지팡이 심볼 2개 이상이면 상태 이상.

### 표창 연격
표창 심볼 2개 이상이면 추가 공격.

### 방패의 반격
방패 2개 이상이면 방어 후 반격.

### 성스러운 회복
힐 2개 이상이면 추가 회복.

## 3. 장비

장비는 심볼 규칙을 변화시키는 방향을 우선합니다.

예:

### 검사의 장갑
검 심볼 1개당 공격 보너스 증가.

### 사냥꾼의 활
활 심볼이 포함된 공격에 관통 효과.

### 마법사의 지팡이
지팡이 심볼에 상태 이상 효과 추가.

### 암살자의 표창
표창 심볼이 2개 이상이면 연타.

### 수호자의 방패
방패 심볼의 방어량 증가.

### 성직자의 로브
힐 심볼의 회복량 증가 또는 보호막 전환.

## 4. 빌드

최종 빌드는 다음의 조합입니다.

심볼 주사위
+
스킬
+
장비
+
캐릭터 특성

목표는 특정 심볼을 중심으로 서로 다른 전투 스타일을 만드는 것입니다.

## 5. 폐기되는 숫자 조건

- 주사위 총합
- 6의 축복
- 홀수/짝수 조건
- 숫자 스트레이트
- 높은 숫자일수록 강화

이 조건들은 심볼 조건으로 재설계합니다.
