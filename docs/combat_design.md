# DiceGod — 전투 설계

> 기준일: 2026-08-28

## 1. 기본값

- 플레이어 HP: 10 / 10
- 기본 주사위: 6개
- 주사위 면: 6개
- 턴당 리롤: 1회
- 개별 잠금 지원

## 2. 전투 순서

1. 턴 시작
2. 6개 주사위 굴림
3. 필요한 결과 잠금
4. 1회 리롤
5. 결과 확정
6. 심볼 개수 계산
7. 2개 조합 시너지 판정
8. 3개 이상 전문화 시너지 판정
9. 공격/보호막/치료/특수 효과 계산
10. 플레이어 행동
11. 적 행동
12. 다음 턴

## 3. 심볼 역할

| 심볼 | 기본 역할 | 전략적 특징 |
|---|---|---|
| 검 | 공격 | 높은 단일 피해 / 강타 |
| 활 | 공격 | 관통 / 방어 무시 |
| 지팡이 | 공격 | 상태 효과 / 지속전 |
| 표창 | 공격 | 추가 타격 / 연타 |
| 방패 | 방어 | 보호막 / 반격 |
| 힐 | 회복 | HP 회복 / 수호 |

## 4. 시너지 단계

### 2개 시너지

2개 결과는 런 초반부터 노릴 수 있는 기본 빌드 방향입니다.

- 검 2 → 검의 강타
- 활 2 → 관통 사격
- 지팡이 2 → 화염 주문
- 표창 2 → 연속 표창
- 방패 2 → 수호 반격
- 힐 2 → 성스러운 치유
- 검 + 방패 → 검벽
- 활 + 표창 → 그림자 습격
- 지팡이 + 힐 → 생명 연성
- 방패 + 힐 → 성역
- 검 + 표창 → 칼날 폭풍
- 활 + 지팡이 → 마력 화살

### 3개 시너지

3개 이상은 특정 심볼을 적극적으로 밀었을 때 발생하는 전문화 보너스입니다.

- 검 3 → 검의 군세
- 활 3 → 천공의 사격
- 지팡이 3 → 대마법진
- 표창 3 → 수리검 폭우
- 방패 3 → 철벽 진형
- 힐 3 → 성자의 기도
- 검 2 + 방패 → 전쟁의 삼각형
- 지팡이 2 + 힐 → 마도 수호
- 활 2 + 표창 → 암살자의 삼각형

한 번의 굴림에서는 3단계 시너지 보너스를 최대 2개까지만 적용하여 6개 주사위가 특정 조건을 동시에 만족할 때 효과가 폭발하지 않도록 제한합니다.

## 5. 시너지 설계 원칙

시너지는 단순한 숫자 증가가 아니라 **서로 다른 플레이 방식을 만드는 것**을 목표로 합니다.

- 검: 강한 한 방
- 활: 적 방어를 무력화
- 지팡이: 상태 효과로 장기전
- 표창: 다단 공격
- 방패: 생존 + 반격
- 힐: 체력 유지 + 수호

또한 혼합 시너지를 제공하여 한 심볼만 모으는 것이 항상 최적이 되지 않게 합니다.

## 6. 런 중 성장과 연결

대장간의 면 교체/강화는 위 시너지의 확률과 조합을 바꾸는 핵심 선택입니다.

예를 들어 `힐 → 검`은 즉시 공격 기대값을 높이지만 힐 시너지와 생존력을 잃습니다. 따라서 주사위 개조는 단순 강화가 아니라 **현재 런의 목표 빌드를 선택하는 행위**입니다.

## 7. 보스

보스는 전용 심볼을 사용합니다.

- 화염군주
- 빙결왕
- 역병군주
- 혈왕
- 폭풍신
- 거암왕
- 운명의 신
- 공허신

보스별 행동 패턴은 향후 시너지 빌드의 카운터가 되도록 확장합니다.

## 8. 밸런스 안전장치

- 기본 효과는 낮은 수치로 유지
- 2개 시너지는 자주 볼 수 있지만 결정적인 승리를 보장하지 않음
- 3개 시너지는 강력하지만 특정 결과가 필요함
- 3단계 시너지 동시 적용은 최대 2개
- 혼합 시너지 제공
- 영구 공격력/HP 인플레이션 금지
- 런 종료 시 시너지 초기화

## 9. 폐기 규칙

숫자 합산, 홀짝, 스트레이트, 높은 숫자 보너스는 사용하지 않습니다.
