# DiceGod — 신성 심볼 시스템

## 핵심 개념

보스는 단순한 최종 보상이 아니라 **새로운 신의 힘을 주사위에 새길 수 있는 관문**이다.

보스를 처치하면 해당 보스의 신성 심볼 1종을 획득한다.

그 즉시:

**보스 처치 → 신성 심볼 획득 → 보유 주사위 선택 → 6면 중 1면 선택 → 해당 면을 신성 심볼로 변경**

이렇게 만들어진 주사위는 환생 시 계승할 수 있다.

## 대장간과의 차이

### 일반 대장간

- 6개 면 중 1개 선택
- ⚔️ / 🏹 / 杖 / ✦ / 🛡️ / ✚ 중 원하는 기본 심볼로 변경
- 골드 사용
- 같은 주사위를 반복 개조할수록 비용 증가

### 신성 각인

- 보스 처치 보상으로만 획득
- 골드가 필요하지 않은 대신 **보스 처치라는 희귀한 기회**가 필요
- 6개 면 중 1개를 선택
- 해당 면을 신성 심볼로 변경
- 신성 심볼은 최대 2면까지 권장
- 신성 심볼이 붙은 주사위가 환생 계승 대상이 될 수 있음

## 첫 번째 신들

| 보스 | 신 | 심볼 | 효과 |
|---|---|---|---|
| 황금왕 | 도박의 신 | 💰 황금 | 전투 종료 골드 +1 |
| 전쟁군주 | 전투의 신 | 💥 크리티컬 | 해당 턴 최종 공격 ×2 |
| 대마도사 | 지혜의 신 | 🔮 예지 | 리롤 후 주사위 1개의 결과를 미리 확인 |
| 생명의 여왕 | 생명의 신 | ❤️ 생명 | 치료 심볼의 회복량 +1 |
| 광전사 왕 | 전쟁의 신 | ⚡ 광전 | HP 50% 이하일 때 공격 피해 +1 |
| 철벽의 수호자 | 수호의 신 | 🛡️ 성역 | 방패 2개 이상이면 추가 보호막 +1 |
| 운명의 사도 | 운명의 신 | ⭐ 운명 | 턴당 1회 심볼 1개를 다른 기본 심볼로 간주 |
| 죽음의 왕 | 죽음의 신 | ☠️ 사신 | 적 HP 25% 이하일 때 공격 피해 +3 |

## 설계 원칙

신성 심볼은 단순 공격력 증가보다 **플레이 방식을 바꾸는 효과**를 우선한다.

- 💰 황금: 경제 빌드
- 💥 크리티컬: 폭딜 빌드
- 🔮 예지: 안정적인 리롤 빌드
- ❤️ 생명: 회복/생존 빌드
- ⚡ 광전: 저체력 위험 빌드
- 🛡️ 성역: 방어/보호막 빌드
- ⭐ 운명: 조합 완성 빌드
- ☠️ 사신: 마무리 빌드

## 보스 보상 연출

보스 처치 직후 일반 보상 화면과 분리된 **신성 보상 화면**을 보여준다.

1. `신의 이름`
2. `신성 심볼 아이콘`
3. 짧은 신의 대사
4. 심볼 효과
5. 각인할 주사위 선택
6. 각인할 면 선택
7. 각인 연출
8. 완성된 주사위 미리보기

예:

> **도박의 신이 당신을 선택했습니다.**
>
> 💰 황금 심볼을 당신의 주사위 한 면에 새길 수 있습니다.

## 신성 심볼 밸런스 규칙

- 한 주사위의 신성 심볼 최대 2면
- 동일 신성 심볼의 중첩은 기본적으로 동일 효과를 곱연산하지 않는다.
- 💥 크리티컬 2면이라고 피해 ×4가 되지 않는다.
- 💰 황금 2면은 골드 +2가 가능하므로 경제력과 전투력의 교환관계를 유지한다.
- 신성 심볼은 일반 대장간에서 다른 기본 심볼로 덮어쓸 수 있으나 **신성 심볼 자체를 다시 얻을 권리는 별도로 유지**한다.
- 신성 심볼을 잃어버린 경우 이미 도감에 등록한 신의 힘은 다시 획득 가능하다.

## 환생과의 연결

죽으면 보유 주사위 중 단 하나를 선택한다.

선택한 주사위는 다음 생에:

- 6면 구성
- 대장간 개조
- 면 강화
- 신성 심볼
- 특수 태그
- 보스 주사위 고유 효과

를 모두 유지한다.

따라서 보스전의 보상은 단순히 `강한 아이템`이 아니라 **다음 생까지 남길 유산을 만드는 선택**이 된다.

## 장기 콘텐츠 확장

향후 신을 추가할 때는 다음 원칙을 따른다.

- 신 1명 = 핵심 플레이 스타일 1개
- 심볼 1개 = 명확한 전투/경제/리롤/생존 변형 1개
- 보스 패턴은 자신의 신성 심볼을 사용하는 빌드에 대한 카운터를 포함
- 신성 심볼끼리 조합했을 때 새로운 빌드가 생기도록 설계

예:

**💰 황금 + 🔮 예지**
→ 안정적인 경제 빌드

**💥 크리티컬 + ☠️ 사신**
→ 보스 마무리 폭딜 빌드

**❤️ 생명 + 🛡️ 성역**
→ 장기전 생존 빌드

**⭐ 운명 + ⚔️ 검**
→ 원하는 공격 조합을 강제로 완성하는 빌드
