# DiceGod — 신성 심볼 확장 설계

> 상태: 미래 확장안. 현재 기본 6면 심볼과 별도 계층으로 관리합니다.

## 개념

보스 보상을 통해 기본 심볼을 넘어서는 특수 효과를 주사위에 부여하는 시스템입니다.

예정 후보:

- 💰 황금 — 경제
- 💥 크리티컬 — 폭딜
- 🔮 예지 — 리롤/예측
- ❤️ 생명 — 회복
- ⚡ 광전 — 저HP 공격
- 🛡️ 성역 — 보호
- ⭐ 운명 — 심볼 변환
- ☠️ 사신 — 마무리

## 구현 원칙

신성 심볼은 기본 심볼 ID 1~6과 충돌하지 않는 별도 ID/효과 계층을 사용합니다. 일반 주사위 판정 코드에 신성 효과를 하드코딩하지 않고 데이터/효과 계층에서 처리합니다.

## 현재 상태

런 상태에 신성 각인 기록과 최대 면 수 제한을 위한 데이터 구조가 있으나, 이 문서의 모든 신성 콘텐츠를 완성 기능으로 간주하지 않습니다. 실제 완료 표시는 로드맵과 CI 결과에 맞춰 갱신합니다.
