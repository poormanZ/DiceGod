# DiceGod — 성장 시스템 설계

## 1. 런 중 성장

한 번의 런 동안 플레이어는 심볼 중심 콘텐츠를 획득합니다.

- 심볼 주사위
- 주사위 개수 증가
- 스킬
- 장비
- 일시적 심볼 강화
- 리롤/잠금 강화

런이 끝나면 런 중 빌드는 기본적으로 초기화됩니다.

## 2. 심볼 중심 성장

성장은 단순 공격력 증가보다 특정 심볼의 활용법을 확장하는 방향을 우선합니다.

예:

- 검 출현 확률 증가
- 활 관통 효과
- 지팡이 상태 이상
- 표창 연타
- 방패 반격
- 힐 회복 강화

## 3. 영구 성장

영구 성장은 새로운 플레이 방식을 여는 방향을 우선합니다.

- 새로운 심볼 주사위 해금
- 새로운 심볼 특화 스킬 해금
- 새로운 장비 해금
- 새로운 캐릭터 해금
- 새로운 던전 콘텐츠 해금

## 4. Power Dice

보스 클리어 후 Power Dice를 해금합니다.

Power Dice는 높은 숫자가 아니라 공격 심볼 등장 확률을 높이는 방식으로 설계합니다.

## 5. 프로토타입

현재 전환 단계에서는 전투의 즉각적인 재미를 우선합니다.

먼저 3개 심볼 주사위의 굴림 → 잠금 → 리롤 → 공격/방어/치료 루프를 검증한 후 성장 콘텐츠를 확장합니다.
