# DiceGod — 성장 시스템 설계

> 기준일: 2026-08-28

## 1. 성장의 두 층

DiceGod은 성장 시스템을 **런 성장**과 **메타 성장**으로 분리합니다.

### 런 성장

현재 런의 전투력을 높입니다.

- 주사위 면 교체
- 면 강화
- 심볼 태그
- 심볼 확률 변경
- 장비
- 스킬
- 시너지
- 골드

런이 끝나면 대부분 초기화됩니다.

### 메타 성장

다음 런의 선택지를 늘립니다.

- 새로운 주사위 타입
- 새로운 심볼 효과
- 새로운 이벤트
- 새로운 보스
- 새로운 대장간 옵션
- 새로운 유산
- 새로운 시작 선택지

메타 성장으로 직접적인 공격력/HP를 무한히 쌓는 구조는 지양합니다.

## 2. 사망 시 남는 것

사망 후에는 런의 실제 전투력 대신 다음을 남깁니다.

- 런 통계
- 발견 기록
- 신규 콘텐츠 해금
- 메타 재화
- 유산 관련 진행도

## 3. 완전 초기화 대상

- 현재 HP
- 골드
- 런 장비
- 런 버프
- 런 중 면 강화
- 현재 주사위 면 구성
- 런 전용 시너지

## 4. 유산

기존의 '환생 주사위 1개를 그대로 계승'하는 개념을 폐기하고 **유산**으로 재정의합니다.

유산은 다음 런의 전략적 선택지를 변경합니다.

예:

| 유산 | 효과 방향 |
|---|---|
| 전사의 유산 | 공격 심볼 관련 선택지 확대 |
| 수호자의 유산 | 방패/힐 관련 선택지 확대 |
| 마법사의 유산 | 지팡이 관련 선택지 확대 |
| 도박사의 유산 | 고위험 이벤트 해금 |
| 신성의 유산 | 신성 심볼 콘텐츠 해금 |

유산은 완성된 강력한 주사위를 제공하지 않습니다.

## 5. 유산 슬롯

유산은 제한된 슬롯에 장착합니다.

슬롯 수가 많아질수록 조합의 폭은 넓어지지만, 시작부터 런의 정답을 제공하지 않도록 각 유산의 영향력을 제한합니다.

## 6. 메타 재화

메타 재화는 콘텐츠 해금에 사용합니다.

권장 사용처:

- 새 주사위 타입
- 새 심볼 효과
- 새 이벤트
- 새 보스
- 새 대장간 옵션
- 유산

비권장 사용처:

- 영구 공격력 +N
- 영구 HP +N
- 영구 피해 감소
- 완성형 주사위 즉시 지급

## 7. 보스 보상

보스 클리어 시 일반 런 종료보다 강한 메타 보상을 제공합니다.

핵심은 **유산 선택권 또는 새로운 콘텐츠 해금**입니다.

## 8. 밸런스 원칙

1. 런 중 강함은 크게 허용한다.
2. 런 밖의 영구 전투력 증가는 최소화한다.
3. 영구 성장은 선택지를 늘린다.
4. 유산은 빌드 방향을 제시하되 완성시키지 않는다.
5. 메타 해금은 새로운 플레이 방식을 제공해야 한다.
6. 실패해도 새로운 것을 발견할 수 있어야 한다.
