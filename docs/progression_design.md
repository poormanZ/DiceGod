# DiceGod — 성장 시스템

## 현재 상태

기본 전투의 심볼 루프를 우선 안정화합니다. 런 상태에는 골드, HP, 주사위 면, 대장간/신성/환생 관련 상태가 준비되어 있지만 모든 성장 기능을 최종 완료 상태로 간주하지 않습니다.

## 런 중 성장 방향

- 주사위 면 변경
- 면 강화
- 장비
- 스킬
- 심볼 확률/조합 변화
- 리롤/잠금 개선

## 영구 성장 방향

환생과 계승 주사위는 장기 성장의 핵심 후보입니다. 계승 주사위가 다음 런의 빌드 방향을 결정하도록 설계합니다.

## 원칙

새 성장 요소는 숫자 합산을 되살리지 않고 심볼의 등장/조합/효과를 변화시키는 방식으로 설계합니다.
