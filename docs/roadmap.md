# DiceGod — 개발 로드맵

## 핵심 시스템 전환 — Action Symbol Dice

기존의 `1~6 숫자 주사위 → 합산 공격력` 구조를 폐기하고, **행동 심볼 주사위**를 DiceGod의 핵심 전투 시스템으로 전환합니다.

기본 6면은 다음과 같습니다.

- 검 — 공격
- 활 — 공격
- 지팡이 — 공격
- 표창 — 공격
- 방패 — 방어
- 힐 — 치료

검/활/지팡이/표창은 초기에는 각각 공격 자원 1개로 계산하고, 향후 스킬·장비·특수 주사위를 통해 서로 다른 전투 스타일을 만듭니다.

→ 3개 주사위 굴림
→ 심볼 확인
→ 원하는 주사위 잠금
→ 1회 리롤

→ 스킬/장비 효과 적용
→ 행동 실행
→ 적 행동
→ 다음 턴

DiceGod의 재미의 중심을 **'높은 숫자를 뽑는 것'에서 '필요한 행동 심볼을 만들고 조합하는 것'으로 전환합니다.**
