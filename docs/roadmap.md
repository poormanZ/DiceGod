> 기준일: 2026-08-29
> 방향: **주사위 중심 로그라이크 + 선택지 확장형 메타 성장**

## 0. 핵심 설계 원칙

- 전투의 주인공은 6면 심볼 주사위다.
- 런 중 강함은 대부분 런 종료와 함께 사라진다.
- 영구 성장은 수치 인플레이션보다 새로운 선택지/빌드/콘텐츠를 늘린다.
- 죽어도 기록·해금·유산 선택지가 남아 재도전의 의미가 생긴다.
- 강력한 완성 주사위를 그대로 다음 런에 계승하지 않는다.
- 모든 화면은 1280×720 안전 영역을 우선하며 작은 화면에서는 스크롤로 콘텐츠를 보장한다.

### 확정 시너지 규칙

- 2개 시너지는 조건 충족 시 1회 발동
- 3개 시너지는 조건 충족 시 발동하며 한 굴림 최대 2개
- 동일 시너지는 중복 발동하지 않음
- 단일 시너지는 해당 심볼 장비 태그 필요
- 혼합 시너지는 구성 심볼 중 하나의 장비 태그로 활성화
- 기본 심볼 효과는 시너지와 무관하게 항상 적용

상세 규칙: `docs/symbol_synergy_rules.md`

### 전투 보상 규칙

- 일반 전투: 골드 30/40/50G, HP +1, 주사위 개조 중 하나 선택
- 엘리트 전투: 골드 70/90/120G, HP +2, 주사위 개조 중 하나 선택
- 주사위 개조는 런 주사위의 실제 면을 직접 변경
- 보상 화면에 변경 대상 주사위/면/심볼을 미리 표시
- 보상 생성과 적용은 `CombatRewardSystem` 하나를 통해 처리
- 골드/HP/주사위 개조 모두 영구 성장 데이터와 분리

### 상점/이벤트 규칙

- 상점은 구매 가능한 상품만 활성화하고 구매 후 중복 구매를 막는다.
- 주사위 교체는 가장 낮은 점수의 런 주사위를 교체하므로 완성 빌드를 무작정 파괴하지 않는다.
- 대장간은 런당 심볼 변경 1회를 기본 제한하고, 면 강화는 선택 면별 누적 비용을 적용한다.
- 캠프는 안전한 회복, 상점/대장간은 골드 투자, 도박은 고위험 골드 변동, 신전은 HP↔골드 교환, 수수께끼는 고위험 랜덤 보상으로 역할을 구분한다.
- 이벤트 화면에는 각 이벤트의 위험/보상 성격을 표시한다.
