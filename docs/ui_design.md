# DiceGod — UI 설계

## 1280×720 기준

현재 프로젝트의 기준 뷰포트는 1280×720입니다. Canvas Items stretch를 사용하며, 전투의 핵심 정보가 화면 밖으로 잘리지 않도록 구성합니다.

## 전투 화면

- 적 이름/HP/다음 공격
- 플레이어 이름/HP/보호막
- 전투 피드백
- 6개 주사위
- 리롤/확정/스킬/행동 버튼

## 주사위 배치

6개 주사위는 기본적으로 **3×2** 배치를 사용합니다. 숫자는 표시하지 않고 심볼을 크게 표시합니다.

⚔️ 🏹 🔮
🗡️ 🛡️ ❤️

잠금 상태는 색상/확대/툴팁으로 구분합니다.

## 피드백

- 굴림: 팝 애니메이션 + SFX
- 잠금: 강조 + 짧은 확대
- 공격: 주사위 강조 + 공격 SFX
- 피해: 화면/주사위 피드백
- 회복/보호막: 상태값 즉시 갱신

## 반응형 원칙

좁은 화면에서도 6개 주사위와 주요 버튼이 잘리지 않아야 합니다. 고정 폭 UI를 늘리는 것보다 컨테이너 기반 배치를 우선합니다.
