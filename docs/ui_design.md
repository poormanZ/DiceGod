# DiceGod — UI 설계

## 1. 전투 화면

전투 화면은 심볼을 즉시 읽을 수 있도록 구성합니다.

- 플레이어
- 적
- 플레이어 HP
- 적 HP
- 공격/방어/치료 결과
- 심볼 주사위
- 잠금 상태
- 리롤 버튼
- 결과 확정 버튼
- 스킬
- 행동 실행
- 전투 피드백

## 2. 주사위 UI

주사위는 숫자를 표시하지 않습니다.

각 면은 다음 심볼 중 하나를 크게 표시합니다.

`⚔️ 🏹 🪄 ✦ 🛡️ ✚`

툴팁에는 심볼 이름과 현재 잠금 상태를 표시합니다.

예:

`⚔️`
검 · 잠금

## 3. 결과 요약

최종 결과 확정 후 주사위 아래 또는 전투 정보 영역에 다음을 표시합니다.

`⚔️ 공격 2   🛡️ 방어 1   ✚ 치료 1`

플레이어가 결과를 계산하지 않아도 현재 행동이 무엇인지 바로 이해할 수 있어야 합니다.

## 4. 피드백

- 공격 → 공격 심볼 강조 + 적 피격
- 방어 → 방패 강조 + 피해 감소 숫자
- 치료 → 힐 강조 + HP 상승
- 리롤 → 주사위 회전/팝 애니메이션
- 잠금 → 테두리/확대/색상 변화
- 확정 → 최종 행동 요약

## 6. 1280×720 기준

현재 전투 UI는 1280×720 기준으로 전체 화면이 보이도록 유지합니다.

주사위 3개를 먼저 안정적으로 배치하고, 최대 6개 확장은 가로/2줄 배치로 확장합니다.

## 7. 웹/반응형

- 데스크톱 브라우저 우선
- 1280×720 기준 회귀 테스트
- 좁은 화면에서 주사위가 잘리지 않도록 2줄 배치 고려
- 심볼 크기는 숫자보다 크게 유지
