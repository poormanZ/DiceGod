# DiceGod — UI 설계

## 1. 전투 화면

전투 화면에서 다음 정보를 명확하게 보여줘야 합니다.

- 플레이어
- 적
- 플레이어 HP
- 적 HP
- 주사위
- 주사위 잠금 상태
- 리롤 버튼
- 결과 확정 버튼
- 스킬
- 전투 결과 피드백

## 2. 주사위 UI

주사위는 가장 중요한 UI 요소입니다.

각 주사위는:

- 현재 숫자가 명확하게 보여야 합니다.
- 잠금 상태를 쉽게 구분할 수 있어야 합니다.
- 클릭 또는 터치로 잠글 수 있어야 합니다.
- 리롤될 때 시각적인 피드백이 있어야 합니다.

권장 구조:

적

적 HP

----------------

플레이어 HP

[ 주사위 ][ 주사위 ][ 주사위 ]

[ 리롤 ]

[ 결과 확정 ]

[ 스킬 ]

[ 공격 ]

실제 디자인은 개발하면서 개선합니다.

## 4. 웹 고려사항

최소한 다음 환경을 고려합니다.

- 마우스
- 키보드
- 일반적인 데스크톱 브라우저 크기

첫 번째 프로토타입에서는 모바일 대응을 필수로 하지 않습니다.
