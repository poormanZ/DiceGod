# DiceGod — 공식 게임 진행 구조

## 1. 한 런의 전체 흐름

**일반 전투 → 골드 보상 → 랜덤 이벤트(선택) → 엘리트 몬스터 → 랜덤 이벤트(선택) → 보스 몬스터 → 보스 특수 보상**

랜덤 이벤트는 두 번의 이벤트 구간에서 선택적으로 진입한다. 이벤트를 선택하지 않고 스킵하면 다음 전투 단계로 바로 진행한다.

## 2. 일반 전투

1. 6개 심볼 주사위를 굴린다.
2. 원하는 주사위를 잠근다.
3. 턴당 1회 리롤한다.
4. 최종 심볼을 확정한다.
5. 공격 / 방어 / 치료를 집계한다.
6. 심볼별 특수 효과와 스킬/장비 효과를 적용한다.
7. 플레이어 행동 후 적 행동을 처리한다.
8. 적을 처치하면 골드를 획득한다.
9. 다음 랜덤 이벤트 구간으로 이동한다.

## 3. 랜덤 이벤트

### 캠프

- 플레이어 HP를 회복한다.
- 전투에서 받은 피해를 다음 전투 전에 복구하는 안전한 선택지다.

### 상점

- 골드를 사용한다.
- 장비를 구매할 수 있다.
- 주사위를 구매할 수 있다.
- 구매한 주사위는 현재 런의 주사위 풀에 추가하거나 기존 주사위와 교체한다.

### 대장간

- 보유 주사위를 선택한다.
- 특정 면을 다른 심볼로 수정할 수 있다.
- 기존 면의 성능/등급을 강화할 수 있다.
- 골드를 사용해 현재 빌드를 세밀하게 조정하는 역할을 한다.

### 도박장

- 보유 중인 주사위를 사용하는 별도의 도박 게임이다.
- 주사위 자체를 단순 판매하는 것이 아니라 현재 빌드를 활용해 위험과 보상을 선택한다.
- 도박 결과에 따라 골드 또는 주사위 관련 보상을 얻을 수 있도록 확장한다.

## 4. 엘리트 몬스터

- 일반 몬스터보다 강력하다.
- 일반 전투와 구분되는 전투 패턴과 심볼 요구를 가진다.
- 처치 후 골드/보상을 획득한다.
- 이후 두 번째 랜덤 이벤트 구간으로 이동한다.

## 5. 보스 몬스터

- 런의 최종 전투다.
- 보스마다 고유 패턴과 전투 정체성을 가진다.
- 특정 심볼을 요구하거나 특정 심볼에 약점을 가질 수 있다.
- 보스 처치 시 해당 보스와 연결된 고유 보상을 제공한다.

### 보스 특수 보상

보스 처치 보상은 일반 상점에서 얻는 아이템과 구분한다.

- **보스 전용 특수 장비**
- **보스 전용 특수 주사위**

특수 장비와 특수 주사위는 해당 보스의 전투 스타일을 강화하거나 새로운 빌드 방향을 제공해야 한다.

## 6. 핵심 설계 원칙

- 전투에서 얻은 **골드가 다음 선택의 핵심 자원**이다.
- 랜덤 이벤트는 항상 강제하지 않고 **선택 또는 스킵**할 수 있다.
- 캠프는 생존, 상점은 빌드 확보, 대장간은 빌드 최적화, 도박장은 고위험/고보상 선택을 담당한다.
- 엘리트는 보스 전에 플레이어 빌드를 시험하는 중간 관문이다.
- 보스 보상은 해당 보스를 쓰러뜨린 이유가 느껴지도록 **고유 장비 + 고유 주사위**로 구성한다.
- 주사위는 단순 숫자 강화가 아니라 심볼 구성과 면 수정으로 빌드를 변화시킨다.

## 7. 구현 우선순위

1. 전투 종료 골드 보상
2. 런 골드 상태 저장
3. 전투 → 골드 → 이벤트 → 엘리트 → 이벤트 → 보스 상태 전환
4. 이벤트 선택/스킵 화면
5. 캠프
6. 상점 — 장비/주사위 구매
7. 대장간 — 면 수정/강화
8. 도박장
9. 엘리트 패턴 다양화
10. 보스 패턴 및 보스별 특수 장비/주사위
11. 전체 런 회귀 테스트
