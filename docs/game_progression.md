# DiceGod — 공식 게임 진행 구조

## 현재 런 흐름

**일반 전투 → 이벤트 → 엘리트 → 이벤트 → 보스**를 기본 경로로 사용합니다. 이벤트 종류는 런 시작 시 확정되는 구조를 유지하며, 세부 선택/스킵 동작은 구현 상태를 기준으로 관리합니다.

## 전투

일반/엘리트/보스 전투는 동일한 심볼 주사위 핵심 루프를 공유합니다.

6개 굴림 → 잠금 → 1회 리롤 → 확정 → 공격/보호막/치료 → 적 행동

## 이벤트

현재 프로젝트에는 캠프, 상점, 대장간, 도박장 씬과 런 상태가 있습니다. 각 시스템의 세부 경제/보상 규칙은 심볼 주사위 빌드 시스템과 함께 계속 정리합니다.

## 보스

보스는 최종 전투 관문입니다. 보스 전용 보상과 신성 심볼은 확장 설계로 존재하지만, 최종 구현 완료 여부는 실제 리소스/씬/검증 결과를 기준으로 갱신합니다.

## 핵심 원칙

주사위는 숫자 강화가 아니라 **면 구성과 심볼 선택을 통해 플레이 방식을 바꾸는 자원**으로 발전시킵니다.
