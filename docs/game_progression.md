# DiceGod — 공식 게임 진행 구조

> 기준일: 2026-08-28

## 1. 한 런의 흐름

**런 시작 → 일반 전투 → 보상 → 이벤트 → 엘리트 → 이벤트 → 보스 → 런 종료**

이벤트는 캠프/상점/대장간/도박장 등으로 구성하며, 런 시작 시 일부 경로가 확정되어 반복 플레이의 예측 가능성과 랜덤성을 함께 제공합니다.

## 2. 전투

모든 전투는 동일한 주사위 핵심 루프를 공유합니다.

**6개 굴림 → 잠금 → 1회 리롤 → 확정 → 심볼 조합 → 행동 → 적 행동**

전투의 전략은 숫자를 크게 만드는 것이 아니라 필요한 심볼을 얼마나 안정적으로 확보하느냐에 있습니다.

## 3. 런 중 주사위 성장

전투와 이벤트의 보상은 현재 런의 주사위를 변화시키는 데 집중합니다.

- 면 교체
- 면 강화
- 심볼 태그
- 확률 변화
- 주사위 특성
- 시너지

따라서 같은 기본 6개 주사위라도 런마다 전혀 다른 빌드가 만들어집니다.

## 4. 런 종료

사망 또는 클리어 시 런 중 전투력은 대부분 초기화합니다.

초기화:
- HP
- 골드
- 장비
- 버프
- 주사위 면 구성
- 런 중 강화/시너지

유지:
- 기록/통계
- 신규 콘텐츠 해금
- 메타 재화
- 유산 진행

## 5. 보스

보스는 현재 8종 풀에서 무작위 선택되며 각 보스는 전용 심볼과 효과를 가집니다.

향후 보스마다 행동 패턴과 보상을 차별화하여 특정 빌드가 모든 보스에 통하지 않도록 합니다.

## 6. 난이도

런 횟수 기반 스케일링은 반복 플레이의 긴장감을 높이는 장치입니다.

단, 메타 성장으로 영구 전투력을 계속 올려 스케일링을 상쇄하는 구조는 사용하지 않습니다.

향후에는 고정 런 횟수 증가뿐 아니라 선택형 난이도/도전 규칙으로 확장합니다.

## 7. 보상 설계

보상은 다음 세 범주로 구분합니다.

### 런 보상

즉시 강해지는 보상.

- 골드
- 주사위 면 변경
- 면 강화
- 장비
- 런 버프

### 발견 보상

처음 발견했을 때 영구 해금되는 콘텐츠.

- 새 심볼 효과
- 새 주사위 타입
- 새 이벤트
- 새 보스
- 새 대장간 옵션

### 보스 보상

- 유산 선택권
- 희귀 콘텐츠 해금
- 메타 재화

## 8. 핵심 목표

플레이어가 런을 반복할수록 단순히 수치가 커지는 것이 아니라 **더 많은 빌드와 선택지를 알고, 더 정교하게 주사위를 설계할 수 있게 되는 것**을 목표로 합니다.
