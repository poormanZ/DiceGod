# DiceGod — 공식 게임 진행 구조

## 현재 런 흐름

**일반 전투 → 이벤트 → 엘리트 → 이벤트 → 랜덤 보스**를 기본 경로로 사용합니다. 이벤트 종류는 런 시작 시 확정되는 구조를 유지합니다.

## 전투

일반/엘리트/보스 전투는 동일한 심볼 주사위 핵심 루프를 공유합니다.

6개 굴림 → 잠금 → 1회 리롤 → 확정 → 공격/보호막/치료 → 적 행동

보스 전투에서는 보스마다 하나의 전용 심볼이 추가되어 적 공격과 함께 특수 효과가 발생합니다.

## 난이도

`run_number`가 증가할수록 적 생성 능력치가 강해집니다.

- 일반: HP/공격/방어 점진 증가
- 엘리트: 일반보다 높은 증가율
- 보스: 가장 높은 증가율

스케일링은 `DifficultyScaler`가 담당하며 최대 배율을 둡니다.

## 보스

보스는 8종 풀에서 무작위 선택됩니다. 보스별 전용 심볼과 효과가 다르므로 같은 던전 런 구조에서도 전투 방식이 달라집니다.

보스 처치 시 `RunState.boss_cleared`를 기록하고 보스 보상 흐름으로 연결합니다.

## 이벤트

현재 프로젝트에는 캠프, 상점, 대장간, 도박장 씬과 런 상태가 있습니다. 각 시스템의 세부 경제/보상 규칙은 심볼 주사위 빌드 시스템과 함께 계속 정리합니다.

## 핵심 원칙

주사위는 숫자 강화가 아니라 **면 구성과 심볼 선택을 통해 플레이 방식을 바꾸는 자원**으로 발전시킵니다.
